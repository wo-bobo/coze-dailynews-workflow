# Coze 智能体：每日资讯小助手（DailyNews 工作流自动化）

> 用 Coze 把「人工检索 → 筛选 → 汇总 → 推送」这条每天都要做的重复流程，改造成**无人值守自动运行**的智能体。

## 架构总览

这不是一条裸工作流，而是一个完整的 **Coze 智能体（Agent）**：工作流作为技能挂在智能体下，由智能体负责调度、记忆与交互。

```
┌──────────────────────────────────────────────┐
│           智能体：每日资讯小助手              │
│                                              │
│  模型：豆包 1.5 Pro（深度思考）               │
│                                              │
│  技能：                                      │
│   ├─ DailyNews 工作流（核心：抓取→汇总→推送） │
│   └─ browse 联网浏览插件（补充实时资讯）      │
│                                              │
│  触发器：                                    │
│   ├─ 定时触发：每天自动抓取热点→简报推送      │
│   └─ 对话创建：允许用户在对话中建定时任务     │
│                                              │
│  记忆：长期记忆（跨会话总结并更新用户偏好）   │
│  交互：用户问题建议（对话后自动推荐追问）     │
└──────────────────────────────────────────────┘
```

## 双模式运行设计

| 触发方式 | 场景 | 行为 |
| --- | --- | --- |
| **定时触发** | 每天早晨的固定需求 | 无需任何操作，自动抓取热点资讯 → 清洗汇总成简报 → 推送给用户 |
| **按需触发** | 用户主动想看某类资讯 | 用户在对话中提问，智能体按需调用 DailyNews 工作流，即时返回最新汇总 |

两种触发复用同一条 DailyNews 工作流，维护成本只有一份——改一次汇总规则或输出格式，定时任务和即时问答同时生效。

## DailyNews 工作流内部结构

```
1. 资讯获取     抓取指定来源的热点/最新资讯
      ▼
2. 清洗与筛选   去重、按领域过滤、取 Top N（控制进入大模型的量与 token 成本）
      ▼
3. 大模型汇总   固定结构化输出：标题 + 日期 + 要点摘要
      ▼
4. 输出与推送   定时：主动推送给用户；按需：直接返回对话
```

## 关键设计说明

1. **为什么用智能体包工作流，而不是裸工作流**：工作流只负责"执行"，智能体负责"理解与调度"——用户随口一问"最近 AI 圈有什么大事"，智能体能判断意图并调用工作流，而不要求用户输入固定格式的指令。
2. **长期记忆的用途**：跨会话总结对话内容并更新用户偏好，用户关注领域会逐渐沉淀下来，简报内容随之更聚焦。
3. **对话中创建定时任务**：用户说"以后每天早上也推一份科技新闻"，智能体可以直接创建新的定时任务，不用进设置页手动配置。
